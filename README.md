# The necessary steps to host the event at OpenReview:

- Go to [OpenReview](https://openreview.net/) website
- Enter your login credentials
- Click on [Hosting a Venue](https://openreview.net/group?id=OpenReview.net/Support) (can see at the end of the OpenReview page. Please see the screenshot).
  
![Screenshot from 2024-09-08 23-57-37](https://github.com/user-attachments/assets/43a0146d-922a-40dc-b787-ef75f4cf3af2)

- Find the __OpenReview Support Request__ form and click on it
  ![image](https://github.com/user-attachments/assets/894f0b2f-e4f3-4c9f-bacd-12dc08a6e242)

- Please fill out the registration form
 ![image](https://github.com/user-attachments/assets/94277535-b87f-40c6-b8d2-e2a7e0749fd2)
- Press the __Submit__ button
- Applicant(s) will receive a confirmation email from the OpenReview team once the submission page is activated (typically within one or two days).
- Once the page is activated, you can manage the event via the ___Program Chairs Console___ (see the screenshot)
  ![pc-console](https://github.com/user-attachments/assets/175f8150-7cdd-492b-81ac-7d387fea59df) 

## Revision page:
- Go to the __Program Chairs Console__
- Find the __Full Venue Configuration__ option and click on it (please see the screenshot).
  ![full-venue-config](https://github.com/user-attachments/assets/30d5191b-9a23-4116-ad41-960f6a2c0a72)  
- To update the submission deadline or update the other information, click on __Revision__ button (see the screenshot).
  ![revision](https://github.com/user-attachments/assets/3a578d8a-e2fc-4abf-8b76-41d7f98d2fe4)
- Make the necessary changes and press the __Submit__ button.

## Reviewer's Recruitment:
- Again go to the __Full Venue Configuration__ option and click on it.
- Find the __Recruitment__ option (see the screenshot).
  ![reviewr-recruitment](https://github.com/user-attachments/assets/105f61ea-7ae4-409b-9db1-be4cc8e0e007)
- Click on the __Recruitment__ button (see the screenshot).
  ![recruitment-form](https://github.com/user-attachments/assets/ed3a0462-d56b-407f-9828-3b52a0213809)
- Please provide the list of reviewers, with one per line, in the ___Invitee Details__ textbox. Either tilde IDs (~Atul_Kr._Ojha1), emails (atulkumar.ojha@insight-centre.org or email,name pairs (atulkumar.ojha@insight-centre.org, Atul Kr. Ojha) expected. If only an email address is provided for an invitee, the recruitment email is addressed to "Dear invitee". Please don't use parentheses in your list of invitees.
- Feel free to modify the automatic ___Invitation Email Content___ text if you wish.
- Press __Submit__ button if everything looks good.

## Review Stage:
- After the submission deadline, go to the __Full Venue Configuration__ option and click on it.
- Find ___Review Stage___ option (see the ![revision](https://github.com/user-attachments/assets/3a578d8a-e2fc-4abf-8b76-41d7f98d2fe4) screenshot)
- Please enter the start and end dates for the review. Additionally, select the required options.
- Press __Submit__ button if everything looks good.
